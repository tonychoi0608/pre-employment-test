# 결과 자동 수신 설정 (약 3분, 한 번만 하면 됩니다)

검사 결과가 **구글 스프레드시트에 자동 저장 + gokang.korea@gmail.com으로 메일 발송**되게 하는 설정입니다.
구글 계정만 있으면 되고, 비용은 전혀 들지 않습니다.

## 순서

1. 크롬에서 **script.google.com** 접속 (gokang.korea@gmail.com 계정으로 로그인된 상태에서)
2. 왼쪽 위 **「새 프로젝트」** 클릭
3. 편집기에 있는 기존 내용(`function myFunction()...`)을 전부 지우고,
   이 폴더의 **Code.gs** 파일 내용 전체를 복사해서 붙여넣기
4. **Ctrl+S** 로 저장 (위쪽 "제목 없는 프로젝트"를 눌러 이름을 "인적성검사 수신" 정도로 변경)
5. 오른쪽 위 **「배포」 → 「새 배포」** 클릭
6. 왼쪽 톱니바퀴(유형 선택) → **「웹 앱」** 선택
7. 설정을 이렇게 맞춥니다:
   - 다음 사용자 인증 정보로 실행: **나(gokang.korea@gmail.com)**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 이게 제일 중요합니다
8. **「배포」** 클릭 → **「액세스 승인」** → 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 경고가 나오면: **「고급」 → 「…(안전하지 않음)(으)로 이동」 → 「허용」**
   - 방금 본인이 직접 만든 스크립트라서 나오는 안내일 뿐, 안전합니다.
9. 완료 화면에 나오는 **「웹 앱 URL」** 을 복사합니다.
   (`https://script.google.com/macros/s/……/exec` 모양)
10. 그 URL을 Claude 대화창에 붙여넣어 주세요.
    → Claude가 검사 페이지에 연결하고 인터넷 배포까지 마무리합니다.

## 확인 방법

- 편집기 위쪽에서 함수 `testMail` 을 선택하고 **「실행」** 을 누르면
  gokang.korea@gmail.com 으로 테스트 메일이 옵니다.
- 첫 결과가 접수되면 구글 드라이브에 **「고강이엔지 인적성검사 결과」** 스프레드시트가
  자동으로 생기고, 이후 한 줄씩 쌓입니다.

## 나중에 참고

- Code.gs 내용을 수정했을 때는 「배포」→「배포 관리」→ 연필 아이콘 → 버전 「새 버전」→「배포」
  를 해야 실제 반영됩니다. (저장만 하면 반영 안 됨)
- 메일 발송 한도: 하루 100건 (일반 구글 계정 기준) — 충분합니다.
