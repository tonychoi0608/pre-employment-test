# 고강이엔지 인적성검사 (pre-employment-test)

특장차·선별기 제조기업 **고강이엔지**의 면접 전 인적성검사 웹앱.
단일 HTML 파일로 동작하며, 서버·인터넷 없이도 실행됩니다.

## 실행

`index.html`을 브라우저로 열면 바로 응시할 수 있습니다. (더블클릭 또는 정적 호스팅)

## 검사 구성 (약 40~50분)

| 파트 | 문항 | 측정 |
|---|---|---|
| 성향 진단 | 48 | 도전정신·끈기·문제해결력·조직융화·성실안전·정서안정 + 타당도(바람직성·일관성) |
| 상황 판단 | 10~11 | 공통 5 + 지원 직무별 5~6 시나리오 (제관·용접, 조립·생산, 기계가공, 도장, 설계, 현장 A/S, 생산관리·품질, 경영·전략기획, 사무·관리, 기타) |
| 실무 감각 | 6 | 기계 기초 상식 |
| 일 동기 | 14 | 우선순위(직장에 바라는 조건) + 만족지연 + 림빅 양자택일 12(타고난 동기: 지배·자극·균형 각 8회 대결) |
| 경험 서술 | 5 | 역량별 실제 경험 (AI 교차검증 재료) |

## 워크플로우

1. 지원자가 응시 → 완료 화면 (지원자에게 점수 비공개)
2. 면접 담당자가 **담당자 코드** 입력 → 결과 리포트 (레이더 차트, 자기보고 vs 상황판단, 응답 신뢰도, 동기 프로필, 서술 원문)
3. **"분석 프롬프트 + 데이터 복사"** → Claude에 붙여넣기 → 신뢰도 검증·역량 교차분석·6가지 도구 해석·면접 추천 질문 7개가 담긴 리포트 생성
4. 이력서는 PDF 첨부(내장 pdf.js로 텍스트 추출) 또는 붙여넣기 — 없어도 응시 가능

## 파일

- `index.html` — 실행·배포용 (test-page.html을 HTML 문서로 래핑)
- `test-page.html` — 소스 (claude.ai 아티팩트용)
- `vendor/` — pdf.js 3.11.174 원본 (index.html에 인라인 내장되어 있음)

## 주의

- 담당자 코드 기본값은 소스의 `DEFAULT_PASS`에 있습니다. 실사용 전 결과 화면 하단 **"담당자 코드 변경"**으로 기기마다 바꿔 쓰세요.
- 공개 저장소/URL로 배포하면 문항이 노출됩니다. 지원자가 사전에 연습할 수 있음을 감안하세요.
- 응답·결과는 응시한 브라우저(localStorage)에만 저장됩니다 (최대 30건).
